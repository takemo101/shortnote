# 検証手順と記録

[SPEC.md](../SPEC.md) の受け入れ条件（A01〜A11）を、どう観測し、何をいつ確認し、何が人間の確認待ちかを記す。新しい合格条件は作らない。実施の権限は、ここからは推測せず、依頼で判断する。共通の操作安全・証拠判定は [macOS 共通検証スキル](../.agents/skills/verifying-macos-apps/SKILL.md)、ケースとコマンドの対応は [ShortNote 固有レシピ](../.agents/skills/verifying-shortnote/SKILL.md) に従う。

## 証拠の種類

次を混ぜない。一つの種類の成功を、別の種類の成功として扱わない。

| 種類 | 例 | 何を示すか |
|---|---|---|
| ソース確認 | コードを読んだ | 実装がそう書かれていること。動作は示さない |
| ビルド | `./scripts/build.sh` が成功 | コンパイルとバンドル作成。動作は示さない |
| 自動の実機観測 | `scripts/native-e2e.swift` の pass | 自分で起動した候補の、実ウィンドウ・実入力・書き出し PNG の画素で観測した範囲 |
| 人間の確認 | ⌃⌥N、筆圧、色選択、他アプリへのドラッグ | ユーザーが実機で見て判断したこと |
| 配布物の検査 | DMG のマウント・署名・Gatekeeper | 配布物としての状態 |

## 検証の入口

リポジトリのルートで実行する。

```sh
./scripts/build.sh
/usr/bin/swift scripts/native-e2e.swift "$PWD/build/ShortNote.app/Contents/MacOS/ShortNote" \
  --artifacts "$PWD/build/native-e2e"
```

- `--artifacts` を省略すると `build/native-e2e/` を使う。実行ごとに一意の `run-<日時>/` を 0700 で作り、`report.json`（0600）と、候補の診断出力、検証用の画像を置く。`build/` は Git 対象外。
- 終了コードは、fail があれば 1、なければ blocked があれば 77、全 pass なら 0。stdout の「今回の report」を読む。部分成功を総合成功へ広げない。
- 実行中は、**マウスとキーボードに触れない**。ハーネスが物理ポインタとキーを使う。実行中は、ハーネスが起動した候補が一時的に前面になる。終了時に、前面だったアプリへ戻し、クリップボードの文字列を元に戻す（クリップボードの画像などの非文字データは戻らない）。
- 前提：自分の console セッション、画面ロックなし、ディスプレイが起きている、そして実行元（ターミナルなど）に Accessibility・画面収録・イベント送信が許可されていること。SDK の非プロンプト確認で事前に読み、足りなければ blocked にして、必要な許可を依頼する（[手順](../.agents/skills/verifying-macos-apps/references/preflight-and-permissions.md)）。AI が OS の許可設定を変えない。
- 起動前に、このリポジトリの旧い候補が残っていないか確認する。残っていると、新しい候補はウィンドウを出さずに終了する（C1 が fail になる）。

ハーネスは、自分が起動した PID だけを、起動時刻と実行ファイルを照合して終了する。キーは、候補が前面でフォーカスを持つことを確認してから送る。ポインタは、送信位置の最前面のウィンドウが候補のものであることを確認してから送る。確認できなければ入力せず blocked にする。画像は、候補のウィンドウだけをウィンドウ ID で撮る。

## ケースと受け入れ条件

| C3 | CLI 引数の画像が、ウィンドウ単位のキャプチャでキャンバスに出る | A05 | 他の画像形式 |
| C4 | Accessibility で各操作部品に到達できる（ツール 5、スライダー、チェックボックス） | A03 | 見た目 |
| C5, C5b | 「パスをコピー」で、クリップボードに新しい実在の PNG のパスが入る。書き出しが期待の寸法・画素と一致 | A07, A08 | 「ドラッグで渡す」 |
| C6, C7 | ペンの筆跡が書き出しに出る。ブラシサイズで太さが変わる | A03 | 筆圧（タブレット） |

| T1〜T3, T2a | 文字ツールで入力欄が開き、確定で書き出しに出る（日本語を含む）。Esc は入力だけを取り消し、パネルを隠さない。実キーが入力欄に届く | A06 | IME 変換中の Return、日本語を実キーと IME で入れた場合 |
| P1 | Cmd+V でクリップボードの画像が中央に、キャンバスの 70% に収まって置かれる | A05 | ファイルとしてコピーした画像 |

| M1〜M3 | 移動ツールで画像が動き、Cmd+Z で移動とドロップの順に戻る | A03, A04 | |

### 自動では観測しないもの

次は、ハーネスの範囲外であり、人間の確認か、別の手段が要る。

- **A02**：⌃⌥N。他アプリが前面のままキーを送る形になり、共通スキルの入力安全の規則で、AI は送れない。非アクティブ型パネルのため、ホットキーで出した直後に Cmd+V・文字入力・Cmd+Z が効くかも、この経路でしか確かめられない。
- **A03（色）**：色選択の UI。
- **A08（ドラッグで渡す）**：他アプリ（エージェントの入力欄）へのドラッグ。
- **A09**：ペンタブレットの筆圧。
- **A10**：x86_64 での実行（ビルドに含まれることは `lipo -archs` で確認できるが、実行は未確認）。
- **A11**：起動の速さと常駐時の負荷。
- **A04（文字入力中）**：文字入力中の Cmd+Z・Cmd+V が文字欄へ転送されること（ソース上はそう書かれているが、未観測）。
- **配布物**：DMG の実際の Gatekeeper の挙動（別の Mac で確認する）。

## 人間の確認

確認を依頼するときは、次のように、画面・操作・期待する変化を示す。曖昧な観測は未確認とし、成功にも失敗にも決めつけない。

| 条件 | 操作 | 期待する変化 |
|---|---|---|
| A02 | ターミナルなど別アプリを前面にして ⌃⌥N を押す | ShortNote のウィンドウが最前面に出る。その直後に、キャンバスをクリックして描け、Cmd+V で画像が入り、文字ツールで入力でき、Cmd+Z が効く。Esc で隠れる |
| A09 | ペンタブレットのペンで、軽く・強く押して線を引く | 軽いと細く、強いと太くなる |
| A03（色） | 左上の黒い四角（色選択）をクリックして色を変え、描く・文字を書く | 選んだ色で描かれる |
| A08 | 「ドラッグで渡す」を、コーディングエージェントの入力欄へドラッグして放す | 入力欄に PNG のパスが貼り付き、エージェントが画像を読める |
| A06（日本語） | 文字ツールでクリックし、日本語入力で変換する。変換中の Return は変換の確定。もう一度 Return で文字を確定する | 確定した文字がキャンバスに出て、書き出した PNG に含まれる |
| A04（文字入力中） | 文字入力中に Cmd+V・Cmd+Z を押す | 入力欄の中で貼り付け・取り消しが効き、キャンバスの履歴は動かない |
| A11 | ⌃⌥N を押してから描けるまで／アクティビティモニタで常駐中の CPU | 押した瞬間に描ける。操作していないときの CPU が、ほぼ 0% |
| 配布 | 別の Mac で DMG を開いて、アプリを起動する | 署名なしの場合、Gatekeeper の警告が出る。回避後に起動する |

## 実施記録

過去の fail・blocked・修正は、書き換えず残す。後の再試行は、別の記録として結び付ける。

### 2026-10-15 — native E2E の全ケース

- **対象**：`build/ShortNote.app`（sha256 `4d4bf58e00672fbb4f65eab199b98f2988cd98fbbae47ef21035b29eddb7cf5b`、arm64 + x86_64 の Universal）。ソースはコミット `3017489`（`origin/main`）と同じ。
- **環境**：macOS 27.0.1、arm64、メインディスプレイ 2560×1440。事前確認（セッション・ディスプレイ・Accessibility・イベント送信・画面収録）はすべて true。
- **実行**：`/usr/bin/swift scripts/native-e2e.swift "$PWD/build/ShortNote.app/Contents/MacOS/ShortNote"`。終了コード 0。28 件すべて pass。`report.json` は `build/native-e2e/run-20261015-102341/`（Git 対象外）。
- **含まれない範囲**：上の「自動では観測しないもの」。この記録を、製品全体の受け入れとは読まない。

#### この記録に至るまでの経緯（参考）

- 手動のスモークで、書き出し PNG が左下の約 1/3 に縮んで描かれる不具合を発見し、`CanvasView.renderPNG` にピクセル倍率を掛けて直した。直後の再確認で、キャンバス表示と一致した。
- 最初の手動スモークの一部は、共通スキルの規則に反していた（全画面キャプチャ、名前指定のプロセス終了、フォーカス未確認のキー送信）。そこで得た観測は、この記録の証拠に含めない。以後は、ハーネスの規則に従った実行だけを証拠にしている。
- 文字・貼り付け・ドロップ・移動の追加後、最初の実行は C1 で fail した。以前に `open` で起動して残していた候補（このリポジトリのビルド）が常駐しており、新しい候補が転送して終了したため。記録した PID の起動時刻と実行ファイルを照合して終了し、再実行した。続く実行は、次の 3 点で fail／blocked になった。**いずれもアプリではなくハーネスの不具合**で、ハーネス側を直して再実行した（アプリのコードは変えていない）。
  - ドラッグ元のウィンドウを、検証用の自前の GUI プロセス（`native-dragsrc`）に分けた。CLI のイベントループでドラッグすると、ドロップがアプリへ届かなかった。
  - ドラッグ元ウィンドウの位置の計算が誤っていて、送信位置がウィンドウの外になった（ヒット対象の確認で blocked）。
  - 期待する色の許容幅が狭かった（色管理で G 成分が 0 → 約 0.23 になる）。
- T2a は、日本語 IME を考慮せず、`abc` を期待して fail と出ていた。判定を「入力が届いたこと」に直した。
- ハーネスを一時的に打ち切ったため、起動済みの候補が残った。名前ではなく記録した PID（起動時刻と実行ファイルを照合）で終了した。

### 2026-10-15 — 起動時にウィンドウを出す変更（C18 の追加）

- **きっかけ**：ユーザーが「`just try` で起動しない」と報告した。観測：`just try`（画像なし）は、プロセスが起動して生きていたが、ウィンドウを 1 枚も持たなかった（仕様どおり、常駐するだけで出さない挙動）。SPEC の「起動したらすぐ描ける」に照らし、起動時にウィンドウを出すよう直した（`AppDelegate`）。あわせて、多重起動の転送の通知名を bundle ID から決めるようにした（本番の名前は変わらない）。
- **対象**：`build/ShortNote.app`（sha256 `4adfecdbda5d6924951c187d21f4371f9d4e5c31d82151dcd0f01662a0c90ef1`）。実行したのは、bundle ID だけを `dev.takemo101.shortnote.test` に変えて再署名したコピー（実行ファイルの sha256 `2dfe5af5675ff7e5337447c731a2976295063f6afd0d23d026f2f106fcb5166b`）。ユーザーの常駐インスタンスが動いていたため、その転送・表示に影響しないよう、隔離した。
- **実行**：`/usr/bin/swift scripts/native-e2e.swift <コピーの実行ファイル>`。2 回目の実行は終了コード 0、29 件すべて pass（C18 を含む）。`report.json` は `build/native-e2e/run-20261015-123951/`（Git 対象外）。
- **1 回目の実行（参考）**：C1・C17・C18 は pass。ポインタを使うケース（C6・C8・C9・T1・D1・M1）が、送信前のガード（送信位置の最前面のウィンドウが候補のものか）の拒否で blocked になり、その結果を前提とする C10・C11・C13・C15・M2・M3 が fail になった。これらは描画が行われなかったことの連鎖で、独立したアプリの不具合ではない。このときのパネルの位置は、通常と違った（1 回目の C1 は x=350、C18 は 2 枚目のディスプレイ側）。ガードが何を前面と見たかは、ハーネスがそのときは記録しておらず、特定できていない。D1 の記録は、ドロップ位置の最前面が Cua Driver のオーバーレイ（PID 76043）だったことを示す。ガードが拒否したときの最前面の所有者を出力するようにハーネスを直し、再実行した（アプリの変更はしていない）。2 回目は、この拒否は起きなかった。
- **含まれない範囲**：「自動では観測しないもの」に同じ。常駐中の旧ビルドのインスタンス（ユーザー側）への影響は観測していない。
